# The calibration board

## The board we use

`ChArUco_A4_10x14_20mm_15mm_DICT_4X4.pdf` — every test and every robot
calibration in this project was done with this board.

**Printing.** A4 paper, at **100% scale. Do not use "fit to page" or "shrink to
margins".** Scaling makes the squares something other than 20 mm, and the whole
calibration then carries that scale error. After printing, measure a square with
callipers and enter what you measured in Stage 1.

**Mounting.** Flat against something rigid. Paper that curls is a common source
of calibration error.

The parameters to enter in Stage 1:

| parameter | value |
| --- | --- |
| squares_x | 10 |
| squares_y | 14 |
| square_mm | 20.0 (use your measurement) |
| marker_mm | 15.0 (use your measurement) |
| dictionary | `DICT_4X4_1000` |
| legacy | **true** |

`legacy` must be true. This board was generated by a version of OpenCV before
4.6, which lays out and numbers the markers differently from later ones. Get it
wrong and every ArUco marker is still found, while not one ChArUco corner
matches: measured here, `legacy=true` gives 70/70 markers and 117/117 corners,
`legacy=false` gives 70/70 markers and **0** corners. The tool's automatic
detection can settle this value for you.

## Using your own board

The tool does not require this board. Stage 1 accepts any `squares_x`,
`squares_y`, square and marker size, and dictionary. The parameters are
checked: the marker must be smaller than the square, each side needs at least
3 squares, and the dictionary must hold `squares_x * squares_y / 2` markers —
if it cannot, the tool suggests a larger one from the same family.

If you are unsure about `legacy` or the square counts, use automatic detection:
photograph the board and the tool enumerates the candidates, ranks them by how
many corners each finds, and picks the best match.

Any dictionary family works: 4X4, 5X5, 6X6, APRILTAG and the rest.
